# Java AWT Login Form

A desktop login application developed using Java AWT.

## Features
- Username and password validation
- Role validation
- Empty-field validation
- Login attempt limit (3 failed attempts)
- Successful login opens a welcome page
- Cancel button

## How to Run

Compile:
```bash
javac LoginFormTask.java
```

Run:
```bash
java LoginFormTask
```
